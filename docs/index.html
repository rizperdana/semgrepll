Why semgrepll?

🔒 Offline & Private

Your code never leaves your machine. No API calls to OpenAI or cloud services.

🤖 AI-Powered

Semantic search understands meaning — find code by describing what it does.

⚡ Fast

Local embeddings with caching. Repeated queries: 12s → 0.0006s

🆓 Free

No API keys, no subscriptions. Fully open source (MIT license).

Get Started

# Install
pip install semgrepll

# Index your project
semgrep index /path/to/project

# Search semantically
semgrep search "how does authentication work"
