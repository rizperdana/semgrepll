Local Semantic Code Search

Search your codebase using embeddings. Runs entirely offline — no external APIs, no rate limits. Perfect for AI coding agents.

$ pip install semgrepll

Why semgrepll?

🔒

100% Offline

No external connections. Your code never leaves your machine.

⚡

Fast Embeddings

Auto-detects fastest backend: llama.cpp → ONNX → Ollama.

💾

Smart Caching

Embeddings cached. Re-indexing is instant.

🎯

Semantic Search

Find code by meaning, not keywords. "auth" finds JWT, OAuth, sessions.

🗄️

Hybrid Storage

SQLite for small projects, LanceDB for large codebases.

🔧

Flexible

Any embedding model. Override backends with env vars.

Backend Priority

Auto-detects fastest. Set EMBED_BACKEND to override.

Quick Start

# Install
$ pip install semgrepll

# Index a project
$ semgrep index ./my-project

# Search semantically
$ semgrep search "authentication logic"

# List indexed projects
$ semgrep ls
